## 📌 Project Overview

This project focuses on **analysis of university-related datasets** using Python and Jupyter Notebook.  
The main goal of the project is to perform **Exploratory Data Analysis (EDA)** in order to understand data patterns, trends, and relationships within academic datasets.

The repository is suitable for:
- Data science practice
- Exploratory Data Analysis (EDA)
- Academic and university projects
- Portfolio and resume showcase
